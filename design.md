# Эхо — дизайн сайта

Главная — GEO-продвижение, /audit/ — самостоятельная услуга аудита. Существующий бренд «Эхо» сохраняется.
Референс владельца: https://resend.com. Заимствуем общие принципы: тёмная сцена, редакционная типографика, предметное 3D, воздух; код и графика оригинальные.

- Палитра: угольный фон, тёплый белый текст, приглушённая медь для сигнала и объектов.
- Шрифты: Prata для крупных заголовков, Onest для интерфейса, системный monospace для подписей.
- Главная: асимметричный hero с объёмным резонатором → модели → интерактивная иллюстрация → направления работы → цикл → отдельный вход в аудит → FAQ → бриф.
- Аудит: самостоятельный hero → интерактивное превью отчёта → состав → метод → FAQ → бриф.
- Общие токены в assets/site.css. Фокус видимый, кнопки не переносятся, меню доступно с клавиатуры.
- WebGL без библиотек: металлические кольца, мягкое вращение и реакция на указатель. На мобильных меньше разрешение и частота кадров. Вне экрана и в скрытой вкладке сцена останавливается. При reduced-motion статичный кадр. Без WebGL — SVG.
- Анимации появления короткие и только после успешной инициализации JS; контент доступен без JS.
- Цены не публикуются. Не выдумывать кейсы, отзывы, метрики и гарантии попадания в ответы ИИ.
- По решению владельца контактов и отправки пока нет. Бриф можно скачать локально; явно сообщаем, что данные не отправляются.
- Публикация на GitHub Pages после явного согласия владельца.
