# AiLeeds — дизайн сайта

Главная — GEO-продвижение, /audit/ — самостоятельная услуга аудита. Название бренда — AiLeeds (решение владельца от 02.11.2026).
Референс владельца: https://resend.com. Заимствуем общие принципы: тёмная сцена, редакционная типографика, предметное 3D, воздух; код и графика оригинальные.

- Палитра: угольный фон, тёплый белый текст, приглушённая медь для сигнала и объектов.
- Шрифты: Prata для крупных заголовков, Onest для интерфейса, системный monospace для подписей.
- Главная: асимметричный hero с предметным 3D-рендером AiLeeds → модели → интерактивная иллюстрация → направления работы → цикл → отдельный вход в аудит → FAQ → бриф.
- Аудит: самостоятельный hero → интерактивное превью отчёта → состав → метод → FAQ → бриф.
- Общие токены в assets/site.css. Фокус видимый, кнопки не переносятся, меню доступно с клавиатуры.
- Предметная графика: отдельный ImageGen-рендер фактурного чёрного объекта с монограммой A, WebP с альфа-каналом. Мягкое CSS 3D-движение и реакция на указатель. Вне экрана и при reduced-motion движение выключено. Не называть это интерактивной объёмной WebGL-моделью.
- Анимации появления короткие и только после успешной инициализации JS; контент доступен без JS.
- Цены не публикуются. Не выдумывать кейсы, отзывы, метрики и гарантии попадания в ответы ИИ.
- По решению владельца контактов и отправки пока нет. Бриф можно скачать локально; явно сообщаем, что данные не отправляются.
- Публикация на GitHub Pages после явного согласия владельца.

## Правки владельца и редакционная политика

- Удалить декоративные подписи над заголовками, псевдофилософские лозунги и технические подписи к графике. Не возвращать «Система, а не один текст», «Резонанс», «Сигнал → ответ» и подобное.
- Не показывать фразу «Набор ассистентов согласуем под аудиторию. Названия обозначают платформы для исследования».
- Оффер сообщает услугу, предмет работы и поставку. Заголовки используют понятные коммерческие формулировки GEO/SEO без переспама и неподтверждённых гарантий.
- Уровень графики: предметный рендер с чёрными тактильными материалами, скруглённым корпусом, металлическими фасками и сдержанными золотыми бликами, как в референсе владельца.

- Cookie-уведомление работает на всех страницах. Храним только выбор уведомления 180 дней; аналитики нет.

## Обязательное правило заголовков (02.11.2026)

- Каждый заголовок H1–H6 формулируется вопросом и содержит вопросительный знак. Сразу после него идёт краткий конкретный ответ, затем раскрытие темы. Правило распространяется на услуги, документы, карточки, бриф и cookie-уведомление.
- Вопрос не должен заменять оффер абстрактной философией: он называет задачу клиента, услугу или результат исследования.
- SEO-title также сформулированы вопросами; показывать владельцу точные значения при запросе тайтлов. После изменения title синхронизировать og:title и WebPage.name.
- Не возвращать декоративные подписи над заголовками.
